# 🥗 ระบบผู้ช่วยแนะนำการเลือกอาหารเพื่อสุขภาพ (RAG Health Assistant)

เว็บแอปพลิเคชันตอบคำถามและแนะนำการเลือกอาหารเพื่อสุขภาพด้วยเทคโนโลยี **Retrieval-Augmented Generation (RAG)**

## 🎯 แนวคิดของ Domain
พัฒนาขึ้นเพื่อช่วยให้ประชาชนและผู้สนใจดูแลสุขภาพสามารถค้นหาข้อมูลโภชนาการ การเลือกทานอาหาร การควบคุมหวาน-เค็ม และการอ่านฉลากโภชนาการ ได้อย่างถูกต้อง อ้างอิงจากคลังบทความความรู้ด้านสุขภาพที่เชื่อถือได้

## 🛠️ สถาปัตยกรรมระบบ (Technical Architecture)
1. **Document Loading & Chunking**: แบ่งเนื้อหาจากไฟล์ข้อความใน `data/` เป็น Chunk ขนาด 350 ตัวอักษร (Overlap 60 ตัวอักษร)
2. **Embedding Model**: ใช้ `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`
3. **Vector Database**: ค้นหาบริบทด้วย **FAISS** (IndexFlatIP) พร้อมการตั้งค่า Similarity Threshold (0.40)
4. **Prompt Engineering**: กำหนดให้ AI ตอบเฉพาะจาก Context เท่านั้น หากไม่มีให้ตอบ "ไม่พบข้อมูล"
5. **LLM Engine**: ประมวลผลคำตอบผ่าน **Gemini API** (`gemini-1.5-flash`)

## 💬 ตัวอย่าง Prompt ที่ใช้สั่ง AI
```text
คุณคือระบบผู้ช่วยตอบคำถามด้านโภชนาการและการเลือกอาหารเพื่อสุขภาพ ให้ตอบคำถามโดยอ้างอิงจาก Context ที่กำหนดให้เท่านั้น
ตัวอย่างเช่น 
1.ควรเลือกรับประทานคาร์โบไฮเดรตประเภทใดเพื่อสุขภาพ?
2.การทานอาหารแบบ Plant-based มีหลักการอย่างไร?
3.ปริมาณโซเดียมที่เหมาะสมไม่ควรเกินกี่มิลลิกรัมต่อวัน?
ข้อบังคับเข้มงวด:
1. ให้ตอบคำถามให้อ่านง่าย ชัดเจน สรุปความเป็นข้อๆ ได้หากเหมาะสม
2. หากใน Context ไม่มีเนื้อหาที่ตรงกับคำถาม ให้ตอบว่า "ไม่พบข้อมูล" เท่านั้น
3. อ้างอิงชื่อไฟล์แหล่งที่มาเสมอ
